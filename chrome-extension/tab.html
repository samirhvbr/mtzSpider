Anti-detecção ativas
  • Warm-up: visita o perfil/post antes de começar
  • Jitter ±40%: variação aleatória no delay
  • Pausas humanas: para de 5–20s a cada 15–25 páginas
  • x-ig-www-claim: token de sessão atualizado a cada resposta
  • x-ig-device-id: device ID lido do localStorage da aba
  • Referer correto: cada request indica a origem correta
  • wwwClaim por conta: preservado entre rotações de pool
